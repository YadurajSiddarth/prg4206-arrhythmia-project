ECG normal vs abnormal research prototype

Explainable machine learning on the PTB-XL dataset · lead-II extracted features · XGBoost with SHAP explanations

Not a clinical diagnostic tool. This is a student research prototype. It must never be used to diagnose, treat or make any medical decision. Always consult a qualified clinician.

1 · Choose an input

You can upload a single-row file or a whole table such as data/features.csv; then choose the record to analyse. Extra columns (ids, split, labels) are ignored by the model. Empty cells count as missing values.

PTB-XL 100 Hz records only (the “_lr” files, for example 00001_lr.hea and 00001_lr.dat). The features are extracted in your browser with the same processing as in training; nothing is uploaded.

Leave a field blank to treat it as missing. Amplitudes are in mV. Placeholders show the training median.

About this model

Metrics are on the held-out test fold (PTB-XL fold 10) at a 0.5 threshold. “AUC 95% CI” is a bootstrap interval over the test records. The deployed model is XGBoost.
