# PRG4206 - Machine Learning: ECG Arrhythmia Classification

## Overview
This repository contains the code for a machine learning pipeline that classifies 12-lead ECG signals into diagnostic superclasses using the PTB-XL dataset.

## Setup Instructions
1. Ensure Python 3.8+ is installed.
2. Create and activate a virtual environment.
3. Install dependencies: `pip install -r requirements.txt`

## Running the Code
- `01_eda.py`: Downloads metadata and generates Exploratory Data Analysis visualizations.
